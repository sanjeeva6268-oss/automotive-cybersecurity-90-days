# Automotive Cybersecurity — 90 Days

A 90-day hands-on automotive cybersecurity learning

**The Car Hacker's Handbook — A Guide for the Penetration Tester**
by Craig Smith.

## Goal

Build practical automotive cybersecurity knowledge while creating a
GitHub portfolio containing:

- Automotive threat models
- CAN and OBD-II labs
- Linux SocketCAN exercises
- UDS/ISO-TP diagnostic simulations
- CAN reverse-engineering tools
- ECU security research
- Firmware-analysis exercises
- Embedded security labs
- IVI security research
- V2V security analysis
- SDR/wireless security research
- Final automotive cybersecurity assessment
