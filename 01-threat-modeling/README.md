# Day 1 – Attack Surface

## What We Need to Understand Today?

### Attack Surface

An **Attack Surface** refers to the possible ways an attacker can interact with or attack a target.

In this learning journey, the target we are considering is a **connected vehicle**.

A connected vehicle contains multiple interfaces through which data can enter, leave, or communicate with the vehicle.

Therefore, when analyzing the vehicle's attack surface, we consider **every possible way data can enter or communicate with the vehicle**.

### Examples of Vehicle Interfaces

Some examples include:

- Cellular
- Wi-Fi
- Bluetooth
- USB
- Key Fob
- TPMS
- Diagnostic Port
- CAN
- Infotainment systems

### Key Concept

> **Attack Surface = All possible interfaces and communication paths through which an attacker could interact with the vehicle or influence its systems.**
